Firebase тохиргоо

Нэг удаа тохируулахад хангалттай. Дараа нь автоматаар хадгалагдана.

  1. Браузерт console.firebase.google.com нээ
  2. "Add project" → шинэ project нэр өг → үүсгэ
  3. Project-доо </> (Web) дарж app нэмэ, Firebase Hosting шаардлагагүй
  4. Authentication → Sign-in method → Email/Password идэвхжүүл
  5. Realtime Database → Create database → Test mode → "us-central1" байрлал сонго
  6. ⚙️ Project Settings → Firebase SDK snippet → "Config" → хуулж доор тавь

⚠️ Хэрэв "databaseURL" байхгүй бол Realtime Database идэвхжүүлснийхаа дараа шинэчил
